# 截图目录

把界面截图放进这个目录，README 的「截图」一节会自动显示它们。

建议的文件名（README 里已经引用）：

| 文件名 | 内容 |
|---|---|
| `main.png` | 主界面全貌（含工具栏、运输条、节拍网格、虚拟键盘、进度状态） |
| `chromatic.png` | 半音阶模式：3×12 虚拟键盘 + 格内 `#1`/带八度点的符号 |
| `settings.png` | 设置 →「半音阶」页（36 键映射编辑器、升半音修饰键、黑键策略） |
| `export.png` | 导出的 PNG / PDF 曲谱效果 |

截图提示：

* 用 `Win + Shift + S` 截取窗口，或 `Alt + PrtSc` 截当前窗口；
* 深色主题下建议把窗口放到 1200×820 左右，字看得清；
* 图片宽度控制在 1200px 以内、体积 < 500KB（可以用画图或 [squoosh](https://squoosh.app/) 压一下），
  免得仓库变大。
